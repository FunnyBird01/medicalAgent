# 院内临床智能辅助系统

全本地、离线运行的 PyQt 临床辅助桌面程序。面向院内医生，提供医疗知识库检索、剂量算术核对、急症风险初筛、科室推荐、配伍规则校验、库存查询、病例管理、处方管理与病例统计看板，并通过 ReAct 智能体实现自主工具调用与可审计的推理过程。所有数据、模型、知识库均留存本地，不上云、不联网，适配医院内网私有化部署。

## 核心亮点

- **ReAct 智能体**：大模型自主完成「思考 → 选择工具 → 观察 → 再思考 → finish」循环，替代关键词硬路由，失败自动降级到确定性工作流。
- **患者安全护栏**：绑定病例后自动注入体重、过敏史、孕哺状态、肝肾功能，剂量计算按体重核对，过敏/孕哺/肝肾风险自动拦截提示。
- **流式输出 + 停止生成**：最终回答逐字显示，可随时中断。
- **思考链可视化**：生成过程实时展示思考/工具调用/观察结果芯片，结束后气泡自动收敛为答案。
- **病例全生命周期**：病例建档、绑定会话、处方开具与历史追溯、病人状况与入院/复查时间节点管理、启动统计看板（在院 / 累计 / 待复查 / 今日复查）。

## 启动

```powershell
python -m pip install -r requirements.txt
python run.py
```

首次启动会在 `data/medical_assistant.sqlite3` 建立 SQLite 数据库，并把 `data/knowledge` 中的文档导入 `data/knowledge_index.json`。程序默认启用本机 Ollama，由模型结合会话上下文和工具结果动态生成回复；模型不可用时会明确标注规则兜底，不会把固定模板伪装成模型回答。

## 功能模块

- **会话与审计**：SQLite 保存会话、消息、引用片段、库存、病例、处方与工具调用日志；左侧新建/切换/删除会话。
- **离线 RAG**：TXT/MD/PDF 分块持久化到本地索引；BM25 词法检索 + 稀疏余弦检索 + RRF 重排。
- **临床工具**：体重剂量核对、急症红旗分级、科室推荐、配伍风险、库存查询、知识库检索。
- **病例管理**：病例新建/编辑/复制/删除/导出；每个病例对应独立会话，绑定不同病例时自动新建会话并保留原会话历史。
- **处方管理**：选择当前病例后可开具处方（药品、规格、剂量、频次、疗程、途径、数量、开方医生、开方时间），保留历史，可删除。
- **医生登录**：启动需用开发者预置的医生账号登录，程序内不提供注册，账号仅能由开发者增加。
- **统计看板**：启动时显示累计病例、在院病人、剩余待复查、今日预计复查。
- **快捷指令**：输入框上方一排常用临床问题，一键发起咨询。
- **桌面交互**：聊天气泡、引用来源、系统配置（模型/温度/检索参数/知识库导入）、运行日志、免责声明。

## 演示病例

每个内置医生账号首次使用时会获得一套相互独立的 7 个演示病例。病例号以
`DEMO-医生姓名-01` 至 `DEMO-医生姓名-07` 命名，病例备注中也保存了推荐提问。
演示病例只初始化一次，用户删除后不会在下次启动时自动恢复。

| 病例 | 主要演示功能 | 推荐操作或提问 |
| --- | --- | --- |
| 01 李小童 | 体重剂量计算、今日复查、处方历史 | “对乙酰氨基酚每次 10mg/kg，20kg 儿童每日 4 次，单次和每日剂量是多少？” |
| 02 张小安 | 青霉素过敏拦截 | “这个病例能否使用阿莫西林？请结合过敏史核对。” |
| 03 王静怡 | 孕期用药安全护栏 | “孕 24 周头痛，可以自行服用布洛芬吗？” |
| 04 陈国强 | 华法林配伍、肾功能风险、处方历史 | “服用华法林期间能否同时吃布洛芬止痛？” |
| 05 赵建国 | 急症风险分级、科室推荐 | “患者胸闷、喘息并端坐呼吸，急症风险如何，应去哪个科室？” |
| 06 孙丽华 | 库存查询、处方管理、出院与复查状态 | “查询内科二甲双胍库存余量。” |

可继续演示病例搜索、编辑、复制、删除、会话绑定、处方新增与删除、状态和复查日期更新、统计看板及 CSV 导出。编辑病例时，医生归属等未显示在表单中的系统字段会保留原值，保存后病例不会再从当前医生列表中消失。

## 安全边界

系统是临床辅助软件，不提供诊断、处方或急救替代。所有规则和知识库须经医院药师/临床专家审核后方可院内部署；正式环境还需按权限、备份、变更审批和数据留存规范加固。

## 配置

环境变量：`MEDICAL_DATA_DIR`、`MEDICAL_DB_PATH`、`MEDICAL_INDEX_PATH`、`MEDICAL_TOP_K`、`MEDICAL_RRF_WEIGHT`、`MEDICAL_USE_OLLAMA`、`OLLAMA_MODEL`、`OLLAMA_URL`。配置面板修改作用于后续咨询。

## 目录结构

```text
medical_assistant/
  config.py     # 本地路径、模型与检索参数
  models.py     # Source / SearchResult / InventoryItem / AgentEvent / Prescription
  storage.py    # SQLite 会话/消息/库存/病例/处方/审计持久化
  rag.py        # 文档导入、分块、BM25+稀疏余弦+RRF 混合检索
  tools.py      # 剂量、急症、分诊、配伍、库存、知识检索工具
  agent.py      # ReAct 智能体、安全护栏、流式输出、失败兜底
  gui.py        # PyQt6（兼容 PyQt5）桌面界面
data/knowledge/ # 示例医疗文档，可替换为经审核的院内资料
run.py          # 启动入口
```
